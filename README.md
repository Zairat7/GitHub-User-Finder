# GitHub User Finder

**Автор:** [Сабанова Фатимат]

## Описание
Приложение для быстрого поиска профилей пользователей GitHub и сохранения их в локальный список избранного. Написано на Python с использованием графической библиотеки CustomTkinter.

## Как использовать API
Программа использует публичное [GitHub REST API](https://github.com).
1. Приложение отправляет GET-запрос по адресу `https://github.com{username}`.
2. Полученные данные (логин, имя, ссылка) выводятся на экран.
3. Дополнительная авторизация (Token) не требуется для базовых запросов (лимит 60 запросов в час).

## Примеры использования
1. Запустите программу: `python main.py`.
2. Введите в поле `mojombo` (один из основателей GitHub).
3. Нажмите кнопку "Поиск".
4. Если пользователь найден, нажмите "В избранное", чтобы сохранить его в файл `favorites.json`.

   ##Как запустить:
   Установите зависимости:pip install requests customtkinterЗапустите:python main.py

**Тест корректности:**
- Попробуйте нажать "Поиск" с пустым полем — приложение выдаст предупреждение.
- Попробуйте найти несуществующего пользователя — приложение сообщит, что юзер не найден.
